# `/megacave` no Codex

O skill original está instalado em `.agents/skills/megacave/SKILL.md`, no escopo deste projeto. Foi copiado sem alterações de [`JuliusBrussee/caveman`](https://github.com/JuliusBrussee/caveman/tree/main/skills/megacave). A licença Apache 2.0 e o aviso de origem ficam junto do arquivo.

Use `/megacave` ou `/caveman wenyan` para invocá-lo. O modo permanece ativo até `stop caveman` ou `normal mode`. A skill não é ativada automaticamente. Ela usa chinês clássico; para trabalho persistido e avisos de segurança, suas próprias instruções determinam usar texto claro no idioma pertinente.

O skill descreve a concisão como variável e ruidosa; não promete economia garantida de tokens.
